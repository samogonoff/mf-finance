## Цель (из ТЗ)
Оперативное получение данных по задолженности ВГО ГК МФ; контроль динамики Дт и Кт
задолженности. Источники — базы 1С (РФ `MF2012`, ПТИР `buh_PTIR`, КЗ `buh_kz`,
УЗ `brs_buh`/`buh_uz_30`, РБ `buh_markformelle`/`formelle_denom`). У нас они приходят
через FinDWH (GLMF/Premaster) — это агрегат тех же 1С-баз.

**валюты в разных строках: BYN, CNY, руб., USD, EUR** → подтверждает: **одна строка
на (счёт/субсчёт × компания × партнёр × ВАЛЮТА)**, мультивалюта построчно.

## Выручка — точные корреспонденции по странам (из ТЗ)
«Выручка за период — только по контрагентам ГК МФ», по строке (Страна + счёт):

| Страна | Дт | Кт |
|---|---|---|
| РБ | `62.1` | `90.1.1` |
| РФ | `62` | `90.01` **плюс** `76.09` → `90.01` |
| КЗ | `1210` | `6010` |
| УЗ | `4015` | `9010` |

«Выручка за последний месяц» — та же логика за последний календарный месяц от даты
формирования (пример: формируем 19.01.2026 → выручка за декабрь 2025).

> ⚠ Сверить с каноничной `GroupPL='ПРОДАЖИ'`: совпадают ли множества проводок. ТЗ
> задаёт ТОЧНЫЕ Дт/Кт — это эталон; `GroupPL` — удобный прокси, использовать только
> если сходится (gate).

## Группировка (4 уровня)
1. **Компания — Компания партнёр**
2. **Счёт БУ**
3. **Договор**
4. **Документ операции**

## Семантика срока/просрочки
- **Отсрочка по договору** = «Срок оплаты» договора в 1С (image3, «в течение N дней»).
- **Дата оплаты по договору** = дата операции + отсрочка; заполняется ТОЛЬКО на уровне
  «Документ».
- **Задолженность в днях** = дни от (дата операции + срок оплаты) до отчётной даты.

## Что меняет в нашем дизайне (SPEC)
1. ~~**Валюта — построчное измерение**~~ — **ИСКЛЮЧЕНО из скоупа** (решение заказчика
   2026-06-24). Транзакционной валюты долга в FinDWH нет (GLMF/Premaster нормализуют в
   функц. валюту + BYN; см. SPEC §10.7). Суммы — в **BYN-консолидации** (+USD), колонка
   «Валюта» = BYN. Вернуться, если аналитик добавит тр. валюту в GLMF из 1С.
2. **Субсчёт** (DrAcc/CrAcc полностью, напр. 60.01), не только корень 60.
3. **Выручка** — по точным корреспонденциям ТЗ (или подтвердить = `GroupPL='ПРОДАЖИ'`).
4. Колонки «Счёт БУ/Наименование» — условные (только при группировке по счёту).
