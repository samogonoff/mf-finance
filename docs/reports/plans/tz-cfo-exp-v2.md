# Формы расходов ЦФО — v2

Источник требований: `var/ТЗ_формы_ЦФО_тактический_план_v2.docx`, версия 2.1.

В документе описаны шесть форм одного маршрута `TPL-CFO-EXP`: 31 (BY), 32
(BY), 33 (BY), 34 (BY), 37 (BY) и блок 962 (RU) в книге формы 37. Для каждой
формы фиксируются страна, сценарий факта, сценарий планового ввода, годы,
наличие юридического лица и режим полного или полугодового ввода. Эти
параметры собраны в `CfoExpSpec` и не должны выводиться из названия листа.

Значения формы различают пустую ячейку и явный ноль. Плановый ввод разрешён
только в открытых месяцах периода. Ожидание I полугодия складывается из факта
закрытых месяцев и тактики остальных месяцев; для форм 31 и 34 база отклонения
строится по независимым флагам факта и стратегии. При нулевой базе отклонение
равно нулю.

Публикационный ключ для приёмников с колонкой `Компания` включает юридическое
лицо. Поэтому одинаковые код ЦФО, статья, месяц и страна разных юридических
лиц не затирают друг друга; для форм без юридического лица значение ключа
остаётся пустым.

Открытые вопросы аналитика из §14 требуют отдельного решения до включения
автоматических реестров: отбор листа «ИНФО» формы 33 (CodeCFO 490), набор
листов формы 34, назначение листа «ЗП от Припеченко», закрытые месяцы I
полугодия и даты периода ввода. До ответа эти параметры должны приходить из
настроек периода, а не из кода.
